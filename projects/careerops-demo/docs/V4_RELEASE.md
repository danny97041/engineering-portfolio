# CareerOps v4

## 일정표

호스팅에서는 MCP 감사 이벤트를 사이트의 별도 D1 테이블에 저장한다. 일반 조회는 업무 SQLite 이미지의 리비전을 증가시키지 않는다. 업무 쓰기와 해당 감사 이벤트는 하나의 D1 배치로 저장한다. 이 변경으로 일정표·요약·내보내기를 동시에 읽을 수 있다. 대용량 일정 페이지는 다음 offset을 반환해 응답 크기를 제한한다. get_schedule의 bucket=active 또는 export_schedule은 활성 일정을 가져온다. 브라우저에서는 /#schedule에서 바로 일정표를 열 수 있다. 분석 조회가 실패해도 일정 데이터는 독립적으로 표시된다.

## 적합도

공고 목록, 지원 현황, 일정표, 비교, 공고 상세와 평가 목록에서 점수를 기본 표시한다. 합계가 0인 경우 0으로 표시한다. 평가가 없으면 미평가, 근거가 일부만 채워지면 총점 미산정과 가중치 충족률, 입력 버전이 달라진 경우 점수와 이전 평가 표시를 함께 보여 준다. 기존 계산과 저장된 점수를 사용한다.

## 개인화와 ChatGPT

개인화에서 본인이 이미 사용하는 비공개 ChatGPT 대화 주소를 등록하거나 삭제할 수 있다. 직접 대화 URL만 사용한다. 새 탭에서 해당 대화를 열고, 연결된 CareerOps 앱의 권한에서 일정표 같은 요청을 실행한다. URL 저장은 업무 전형이나 자격 프로필 버전을 변경하지 않는다. 대화 내용과 메시지 전송은 사용자의 ChatGPT 세션에서 이뤄진다. [ChatGPT 연결 앱 안내](https://help.openai.com/en/articles/11487775-connected-apps-in-chatgpt)

배포의 D1 감사 로그는 업무 DB의 복원 내역과 별개다. SQLite 다운로드에는 해당 시점의 업무 기록과 앱 설정이 포함된다. 새 D1 도구 감사 기록은 이 다운로드에 포함되지 않는다.
