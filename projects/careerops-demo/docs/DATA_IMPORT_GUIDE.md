# 운영 데이터 가져오기

Work 배치 버전은 1이다. 상위 레코드를 먼저 배치하고 이후 행은 $ref로 앞선 성공 행의 ID를 참조한다. 제출 상태, 공식 일정, 추정 정보는 각 출처의 확인 시점과 함께 대조한다. 한 배치에 30행과 요청 16 KiB를 넘지 않도록 분리한다. 중복·충돌 행은 키를 바꾸기 전에 원인과 변경 여부를 확인한다. 실패 행만 고쳐 새 배치 키로 제출한다.

preview_work_batch와 apply_work_batch는 동일한 서비스 계약을 사용한다. 미리보기 ID는 시험 트랜잭션 안에서 생성된다. 적용 결과의 ID를 후속 배치에 사용한다. 결과 크기 제한이 걸리면 더 작은 배치로 드라이런을 다시 한다. 대안은 Site의 데이터 교환 화면이다.
