# CareerOps v4.1

- 공고 목록과 지원 현황의 오른쪽 끝에서 마감 임박, 추천, 규칙 확인, 결과 대기 등 근거가 있는 특징을 확인할 수 있다.
- 일정표는 5열을 유지한다. 오른쪽 태그에 도착·입실 마감, 조건부, 시간 충돌, 시작 시각 미정, 적합도를 표시한다. 장소·비고를 숨긴 경우 상태 열의 오른쪽에 태그를 유지한다. 다운로드 양식에는 도착과 입실 시간이 텍스트로 포함된다.
- 결과 대기에는 제출 수신, 서류 대기, 검사 완료, 면접 완료, 최종 대기 중인 활성 전형을 포함한다. 전형 상태 자체는 변경하지 않는다.
