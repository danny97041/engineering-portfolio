# CareerOps operational review update

## Recruitment lifecycle

The Current and Closed tabs partition postings by confirmed closure, cancellation or a past Seoul-time deadline. A same-day deadline with no time remains current until the day ends. Closed records retain their exact round, application history and review status. Current unreviewed counts and exports exclude closed postings.

Eligibility evaluates employer qualification criteria. Coding policy, deadline, existing application decisions and explicit exclusions govern future recommendations separately. The source application stage remains visible. Institution type has its own field and the B/C/D scale measures company size.

## Five fit ratings

The independent rubric shows overall role fit, master's research, AI projects, 3–5 year career value, and long-term retention. Each rating can be unknown or carry a single score or range from 0 to 100, a confidence state, a source URL and evidence. Each saved revision includes a date, the reason for change and its posting version. The workspace keeps the existing six-factor weighted assessment separately. Ratings represent fit and have no probabilistic interpretation.

Use the posting's analysis panel or get_fit_profile/save_fit_profile. Existing notes can be reviewed and keyed to an exact posting ID and round before entry. The update includes no bulk conversion of historical notes.

## Scan inbox

Review the source, posting identity and receipt origin before approving, merging, or dismissing. Approval checks for duplicates and sends a new record to the verification queue. Merge requires an exact company, round, role and current posting version. It adds source evidence and retains the posting's core fields and application state. A repeated identical receipt returns the same decision. Existing receipts with no origin are marked unverified. New callers can declare an origin. A dedicated scoped scheduled credential supplies the scheduled origin server-side.
