# 변경 이력

## CareerOps v4.2 · 배포 후보

- 지난 공고를 종료 탭으로 분류하고 고용주 자격과 재추천 사유, 전형 상태를 분리했다.
- 5종 독립 적합도와 검토함 승인·출처 병합·종료 기능을 추가했다.
- 스캔 키 권한 범위, 호스팅 스냅샷 이행, 인증과 캐시를 격리 환경에서 검증했다.

## CareerOps v4.1

- 공고와 일정의 오른쪽에 주요 특징을 태그로 표시한다.
- 제출·검사·면접 완료 후 다음 결과를 기다리는 활성 전형을 대시보드에 집계한다.

## CareerOps v4

- 호스팅 MCP 읽기 감사 기록을 분리하고 일정표 딥링크 및 응답 페이지 제한을 추가했다.
- 적합도 점수·미평가·이전 평가를 기본 표시하고 개인화에 비공개 ChatGPT 대화 링크를 추가했다.

## Phase 4 · 2026-11-25

- REST와 MCP의 공통 쓰기 계약, 스캔 근거 수신함, 실행별 재처리, MCP App 일정표와 비교 카드를 추가했다.
- 소유자 전용 Sites에 합성 D1 시험 MCP를 배포하고 Work 인계 파일을 생성했다.

## Phase 3 · 2026-11-25

- 구조화 자격 규칙, 멱등 등록과 출처 병합, 버전 기반 점수 및 분석 캐시를 추가했다.
- 적합도 비교 막대, 중복 검토 큐, DB 기반 통계와 로컬 처리 계측을 추가했다.

## Phase 2 · 2026-11-25

- 로컬 채용 대시보드와 공고 탐색, 지원 상태 전이, 공고 비교를 추가했다.
- 단일 일정표, 달력, 조건부·날짜 미정 및 비활성 일정, CSV·Markdown·ICS를 추가했다.
- 변경 미리보기, 감사 기반 편집 되돌리기, 일괄 수정 사전 검증을 추가했다.

## 0.1.0 · 2026-11-25 · Phase 1

- 로컬 영구 DB와 전체 초기 스키마, 마이그레이션 무결성, 인스턴스 바인딩을 추가했다.
- 기업·공고·일정 CRUD, 소유자 프로필, 읽기 전용 권한, 버전 충돌 처리, 감사 이력을 구현했다.
- 합성 시드, 운영용 빈 DB 준비, D1 조회 계약, 회귀 테스트 15건과 개발 문서를 추가했다.

## Phase 7–8 · 2026-11-25
- 두 소유자 전용 사이트에 공통 업무 서비스, 영속 리비전 및 복구를 배포했다.
- 마감일 동시 수정, Work 일괄 미리보기·저장, 과거 지원 이력 이전과 검색 페이지 비용을 검증했다.
- 비공개 Work 이전 지시서와 반환 양식을 추가했다.
